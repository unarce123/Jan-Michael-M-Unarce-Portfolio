OPENING THE WEBSITE
1. Extract the project folder.
2. Open index.html in a modern browser, or open the folder in Visual Studio Code.
3. Keep the css, js, and assets folders beside index.html.

3. Update your individual contribution and testing/results sections in the project case studies. The prompts are intentional so you do not claim work or test outcomes you did not complete.
4. Replace the sample documentation previews with your final resume, cover letter, and SOP/developer guide.
5. Add actual project screenshots, repository URLs, and demo links after checking that they work.
